ENGLISH MONSTER WORLD Ver.22  改良版（GitHub Pages用）

前の Ver.21.1 のセーブデータは消さずに更新できます。
【更新手順】
1. GitHub の hirosswb-freedom/english-monster-world を開きます。
2. Code → Add file → Upload files で、このZIPを展開して中身のファイルをアップロードします。
3. 既存の index.html と sw.js が同名で上書きされることを確認し、Commit changes を押してください。
4. Actions の「pages build and deployment」が緑になった後、ホーム画面のアプリを終了して再起動します。
   画面が古い場合は、公開URLをChromeで開き直して再読み込みしてください。
5. 今までのセーブは同じサイトのブラウザー保存領域(localStorage)にあり、通常そのまま使えます。
   ただし、アプリのデータ削除やURL変更をすると引き継がれない場合があります。

このZIPはホーム画面にインストールできるPWA一式です。APKではありません。
更新点：出題順と選択肢シャッフル、苦手問題の復習、正誤と解説、学習記録、学習設定のボタン修正、経験値持ち越し、ミニマップ軽量化。
